# 首版需求确认

## 产品范围

Flutter 开发，优先交付 Android，界面简洁清晰，全部数据本地保存。

## 档案

- 手机号仅支持中国大陆 11 位号码，做格式校验，无需短信验证。
- 有效档案内手机号唯一，创建和修改时检查重复。
- 使用永久稳定的内部标识归集数据，手机号可修改，档案直接切换。
- 删除档案需二次确认并展示手机号及影响范围，删除最后一个档案后进入创建页面，创建后才能继续记录。

## 排便记录与日期状态

- 每条记录表示一次排便，同日允许多条。
- 日期必填，具体时间选填，两个维度必选且不预选。
- 通畅度预设为困难、一般、顺畅，排便量预设为少、中、多。
- 新增和编辑禁止未来日期及未来时刻，按操作时设备当地时间判断。
- 历史日期跨时区保持固定，具体时间保留填写时的当地时间及其时区信息。
- 日期状态包括已记录排便、确认当天未排便、尚未填写。
- 添加排便记录自动解除当天未排便确认，删除最后一条记录回到尚未填写。
- 已有记录时确认未排便，需提示并确认删除当天记录。

## 自定义选项

- 按档案、维度归属，支持新增、改名、停用和重新启用。
- 名称去除首尾空白后为 1～20 个字符，同档案同维度名称唯一，包含预设及停用选项。
- 预设选项固定，自定义选项按创建顺序展示，暂不强制映射预设等级。
- 历史记录保留选择时名称，仅主动重新选择对应维度时更新。

## 备份与导入

- 导出带格式版本号的完整 JSON 备份，包含全部档案、记录、未排便确认、自定义选项。
- 导出前提示包含手机号和排便数据。
- 导入按稳定标识合并，新增数据导入，相同数据跳过，内容冲突保留本机并展示数量。
- 手机号相同但档案标识不同，由用户选择合并目标或跳过。
- 已删除数据保留删除标记，普通合并导入阻止旧数据复活。
- 按档案和日期检查状态互斥，冲突保留本机当天状态，跳过冲突内容并列出日期。
- 导入先校验并预览新增、跳过、冲突数量及档案合并选择，确认后整体提交，失败不留下部分结果。
- 文件损坏、内部状态违反互斥规则、格式版本过高时整份拒绝，低版本通过明确升级规则读取。
- 空白设备导入旧备份只能恢复备份保存时状态。

## 页面范围

- 日历首页支持切换档案和月份、返回今天，显示每日排便次数或未排便状态，查看选中日记录。
- 记录编辑页支持日期、可选时间、两个记录维度及修改、删除。
- 管理页支持档案、选项、备份导入与导出。
- 统计图表、提醒、备注、照片及阅读型导出暂缓。

## 合并与恢复细节

- 档案合并时，同维度同名称选项复用本机选项，其余作为目标档案自定义选项导入。记录保留原名称，关联映射至合并后选项。
- 保存来源档案到目标档案的合并映射，再次导入自动沿用并展示预览，记录保留原稳定标识。
- 完整备份包含删除标记及档案合并映射。删除标记只保留识别所需最小信息，删除档案后清除其手机号及业务内容。
- 删除档案后允许重新使用手机号，新建档案采用全新标识，普通导入跳过受删除标记约束的旧档案。
- 新建和编辑页面存在未保存改动时，返回需确认放弃。保存成功返回选中日期并刷新，修改记录日期后首页切换到新日期。

## 未来后台兼容

首版落实稳定标识、数据版本、修改时间、删除标记和本地数据库升级机制，以数据可迁移为目标。后台账号绑定、登录、同步协议、自动同步及服务端冲突处理待后台需求明确后设计。

## 备份保护与操作体验

- 首版采用明文 JSON 备份，导出确认明确提示未加密，由用户选择保存位置或分享目标。
- 仅按稳定标识判重，不同标识的相似记录均保留，由用户手动判断和删除。
- 首次打开进入创建档案页面，创建后进入当天日历。后续启动恢复上次档案并选中今天，上次档案已删除时选择剩余档案，没有档案时进入创建页面。
- 日历以周一为每周起点，未来日期置灰且不可进入记录操作。每日展示排便次数或未排便，尚未填写留空。
- 当天列表有时间记录按时间升序，无时间记录排在后面并按创建顺序排列。
- 删除单条记录后提供短暂撤销，撤销同时恢复记录并撤回该次删除标记。档案删除继续采用二次确认。

## 最终边界

- 导入时按设备当地时间校验未来日期及未来排便时刻，具体时刻按记录保存的时区信息换算。发现未来排便数据时整份拒绝并说明原因。
- 修改记录日期时，自动解除目标日期的未排便确认，原日期失去最后一条记录时回到尚未填写，整个修改一次性完成。
- 撤销删除时，若当天已确认未排便，提示恢复记录将解除该确认。
- 首版关闭应用数据的 Android 系统云备份，手动导出作为明确备份入口。用户可以主动将导出文件保存到云盘。具体 Android 版本及设备迁移行为在实现阶段核实和验证。
