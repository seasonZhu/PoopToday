# 当前需求确认

2026-11-09，三轮 Q1～Q25 与概念图收敛均已确认。当前完整规则以 [改版规格](../.scratch/poop-today-v1/spec.md) 为准。

## 首页与统计

- 首次启动先创建档案；后续启动恢复上次档案并定位今天。档案失效时选择剩余档案，无档案则建档。
- 首页纵向滚动：月份与当月概览、完整月历、“记录今天”、统计区。档案入口承载手机号，主要记录区域不展示 UID 或手机号。
- 月历始终为月视图，周一起始，支持切月和返回今天。今天描边；未来日期置灰不可操作。有记录显示“2次”等次数，确认未排便显示短横线，未填写留空，附图例。
- 点击日期立即进入当日页面；返回保持浏览月份、最后查看日期和滚动位置。“记录今天”直接进入今天。
- 当月概览显示排便总次数、已排便天数、确认未排便天数、尚未填写天数。当前月仅计算截至今天，历史月计算整月，未来日期不计入未填写。
- 统计区两张分布柱状图共用周／月切换。月统计跟随浏览月份；周统计默认选中日期所在周，周一至周日，可跨月，支持前后周并显示日期范围。
- 通畅度图显示三档次数；排便量图按数值升序显示各值次数，自定义值单列，过多时横向滚动。量值是主观量级，不求和作为实际重量。
- 点击柱子显示次数与占比，不跳转筛选列表。没有记录显示空状态；旧版无法分类的文字显示“旧版未分类”，不猜测等级。

## 当日表单与列表

- 上半部分为新增表单：具体时间选填且默认不填，通畅度与排便量必选且不预选；下半部分为当天记录列表。
- 通畅度仅三档：😣 困难、😐 一般、😌 顺畅，不支持自定义。
- 排便量快捷档位固定为 💩 × 1、💩 × 3、💩 × 5，自定义仅输入 1～99 的整数，不保存为快捷选项，不再提供选项命名、改名、停用管理。
- 保存处理中禁用保存按钮，防止连点；允许同日多条相同内容。保存成功留在当日页，清空表单恢复新增状态，刷新列表并简短提示。
- 点击整条记录回填上方表单进入编辑，明确显示“保存修改”“取消编辑”。保留日期修改能力；修改日期后刷新原日期及目标日期，并在目标日期当日页展示结果。
- 有时间记录按时间倒序，无时间记录排后按创建顺序倒序。每行展示具体时间或“未填写时间”、通畅度、排便量。
- 有实际未保存修改时，离开页面或切换编辑对象需确认放弃，未修改不提示。
- 单条记录点击删除或完整侧滑立即删除，无确认、无撤销；删除最后一条后回到尚未填写。
- “确认当天未排便”为表单下方次要操作；已有记录时需确认批量清空，取消不变更。新增或移入记录解除目标日期未排便确认；移出最后一条后原日期回到尚未填写，相关修改事务提交。
- 新增、编辑及导入禁止未来日期和未来时刻。历史日历日期跨时区固定，具体时间保留填写时当地时间及时区信息。

## 历史数据与档案

- 档案和记录使用各自不可变 UID，手机号不作为身份。普通创建／修改继续校验中国大陆 11 位格式和有效档案手机号唯一。
- 导入例外：相同手机号不同档案 UID，只能作为独立档案导入或跳过，不跨 UID 合并，不新增合并映射；选择器使用短 UID 辅助区分同号档案。
- 同 UID 档案信息由导入覆盖；不同 UID 的记录不按内容自动去重。
- 删除档案仍需二次确认，展示手机号及影响范围；清除其手机号和业务内容，保留最小删除信息。最后档案删除后进入建档，手机号可复用但 UID 全新。
- 旧预设少／中／多映射为 1／3／5；旧自定义文字原样保留。编辑其他字段保留旧值，仅主动重选对应字段才转换。新建不可继续使用旧自定义文字。
- 数据库升级保留实际已有数据、UID、历史文字、时区、日期状态与删除信息，不虚构已有备份格式。

## 备份与导入

- 明文、带格式版本号的 JSON 完整导出全部档案、记录、未排便确认、数值与必要旧版文字、删除信息；不要求新的跨 UID 合并映射。导出前提示未加密且含手机号及排便数据，支持保存或分享，取消及失败不改变业务数据。
- 同记录 UID 同内容跳过，不同内容以导入内容覆盖；本机独有记录保留，文件缺项不是删除命令。重复导入不新增重复记录。
- 导入文件涉及的同档案同日期有效状态优先：导入未排便确认清除本机当天记录；导入排便记录解除本机未排便确认并按记录 UID 合并。其他日期不受影响。
- 导入有效数据可恢复本机已删除的同 UID 对象；显式导入删除状态覆盖本机同 UID 状态。导入前提示“导入内容优先，可能覆盖修改或恢复已删除记录”。删除标记不再阻止有效导入恢复。
- 同一文件同档案同日同时含有效未排便确认和有效记录，或存在矛盾 UID／引用时整份拒绝并列出原因及冲突日期。损坏、不支持的高版本、未来排便数据也整体拒绝。
- 先完整校验与预览，展示新增、覆盖、恢复、跳过数量及日期影响；分类互斥，恢复指本机删除对象变为有效，覆盖指其他同 UID 内容更新，因日期互斥被清除的记录另列影响数。确认前不写入业务数据，事务失败全部回滚。
- 预览后本机变化须重新计算预览并再次确认。支持的旧格式显式升级；空白设备恢复以备份时状态为限。

## 视觉与交付边界

- 已审核概念布局：暖白背景、深色文字、低饱和强调色、轻分隔，少卡片与阴影，emoji 配合简短文字。
- 最终收敛：统一系统无衬线字体、缩小首页标题；按钮和选中态用纯色，去掉渐变和背景纹理。概念图数字仅占位，不作为统计样例或验收数据，表单选中态仅示意。
- Flutter 本地离线应用，优先 Android；关闭 Android 系统云备份，主动导出可保存云盘。已有 iOS 工程及历史构建记录不代表本轮已验证。
- 范围外：提醒、备注、照片、阅读型导出、后台登录与同步、文件加密、跨 UID 档案合并、命名型自定义选项。
- 本轮仅文档改版，未修改代码、未执行构建或行为测试。现有 lib/ 和 test/ 已存在，Ticket 01～03 有历史实施记录；历史通过结果不能证明本轮规则已实现。
