# 首版验收标准

依据七轮已确认需求整理，实施后逐项验证，本文不代表已完成测试。

## 档案与记录

- 首次使用要求创建档案，手机号格式不合规或与有效档案重复时无法保存。
- 不同档案的数据及自定义选项独立，修改手机号后原有记录仍属于原档案。
- 同一天可以保存多条记录，日期与两个维度必填，时间可不填，两个维度初始无预选。
- 新增、编辑与导入均执行未来日期和未来排便时刻限制。
- 切换时区后历史记录日期不变，具体时间保留原填写信息。
- 日期三种状态正确展示，未填写不能被统计或展示为已确认未排便。
- 新增及移动记录到已确认未排便的日期时解除该确认，删除或移出最后一条记录后原日期变为尚未填写。
- 有记录时确认未排便需明确确认删除当天记录。
- 删除单条记录支持短暂撤销，恢复记录时正确撤回删除标记，并处理当天未排便确认。
- 删除档案需二次确认，最后一个档案删除后进入创建页面。相同手机号重新创建时产生新档案标识。

## 选项与页面

- 自定义名称去除首尾空白后满足长度限制，同档案同维度与预设、停用选项均不能重名。
- 自定义选项可改名、停用、重新启用，历史名称保持不变，编辑其他字段不会更新历史名称。
- 日历周一开始，支持切换月份与返回今天，未来日期不能进行记录操作。
- 当天列表按已确认规则排序，未保存改动返回时提示放弃，修改日期保存后首页选中目标日期。
- 启动恢复上次档案并选中今天，上次档案不存在时正确回退。

## 备份与合并

- 明文 JSON 导出前提示未加密及包含的数据，用户可选择保存位置或分享目标。
- 导出内容覆盖全部档案、记录、未排便确认、选项、删除标记及合并映射，删除档案的手机号与业务内容不保留。
- 导入先校验并预览，用户确认前不改变业务数据，提交失败不保留部分结果。
- 同一文件重复导入不产生重复记录，不同标识的同内容记录继续保留。
- 同标识不同内容保留本机并展示冲突数量，日期状态冲突保留本机并列出冲突日期。
- 相同手机号不同档案标识时允许选择合并目标或跳过，合并后选项关联正确，历史名称保持不变。
- 再次导入沿用已有档案合并映射，已删除数据不会因旧备份重新出现。
- 组合验证档案合并后删除记录、再次导入及跨设备备份恢复，确保稳定标识、映射和删除标记共同生效。
- 损坏文件、内部互斥冲突、过高格式版本及未来排便数据导致整份拒绝，错误原因可理解。
- 支持的低版本备份按明确规则升级读取，空白设备恢复结果与备份时状态一致。

## 本地存储与交付

- 断网情况下可完成全部首版核心流程，重启后数据保留。
- 数据库升级保留已有数据，具备稳定标识、数据版本、修改时间和删除标记。
- Android 系统云备份配置按需求关闭，实际设备迁移限制需结合目标版本核实并记录验证结果。
- Flutter Android 构建通过，功能与数据验收结果单独记录。
- 首版范围限定于日历记录、档案、选项和备份管理，后台同步等后续能力另行设计。
