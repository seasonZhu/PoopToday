# 使用版本化备份并按稳定标识合并

> 状态：历史决策。与本轮冲突的条款已由 [ADR 0006](0006-ui-numeric-import-priority.md) 替代。下文原样保留用于追溯，不作为当前实现依据。

首版使用带格式版本号的 JSON 文件完整备份全部档案、记录、未排便确认和自定义选项，导出前提示文件包含手机号与排便数据。导入按稳定标识合并，新增数据导入、相同数据跳过、内容冲突保留本机并显示冲突数量，确保重复导入同一文件不增加重复记录。

手机号相同但档案标识不同的情况由用户选择合并目标或跳过。首版阅读型导出暂缓，删除后重新导入、日期状态冲突及格式升级的细则待后续访谈确认。
