# 固定通畅度、数值排便量与导入优先

日期：2026-11-09
状态：用户已确认，待实施

## 背景与取舍

旧决策支持命名型自定义选项、本机优先导入以及删除标记阻止恢复。新一轮三轮访谈确认简化填写与维护，并接受导入覆盖修改或恢复删除数据的代价。概念布局审核后，用户授权同步规格与任务。

## 决策

- 通畅度固定三档，排便量为 1～99 的主观整数档位，快捷 1／3／5；无命名型自定义选项管理。旧少中多映射为 1／3／5，其他文字保留，主动重选才替换，统计归旧版未分类。替代 ADR 0002 的新选项管理要求，继续保留历史含义。
- 同 UID 内容由导入覆盖，缺项不删除本机独有数据。有效导入可恢复删除对象，显式删除状态也覆盖同 UID。导入涉及日期的有效状态优先解决未排便与记录互斥，文件内部互斥整份拒绝。替代 ADR 0003／0004 的本机优先与阻止恢复条款。
- 同手机号不同 UID 仅独立导入或跳过，不跨 UID 合并、不新增映射。普通建档和修改手机号仍校验唯一性，导入同号为明确例外；短 UID 辅助识别。
- 单条记录直接删除，支持完整侧滑，无确认及撤销。删除最后一条回到尚未填写；档案删除和已有记录时确认未排便仍二次确认。
- 导入前展示覆盖／恢复影响并确认，完整校验、事务提交、失败回滚和重复导入幂等继续保留。

## 结果与关联

ADR 0001 的稳定身份及 ADR 0005 的固定日历日期继续适用。首页改为月历、概览与周月分布统计，当日页改为表单加列表；详细行为与验收以 [当前 Spec](../../.scratch/poop-today-v1/spec.md) 为准。旧 ADR 正文及 Ticket 的原有实施记录保留，但不能用于证明本轮已实现。
