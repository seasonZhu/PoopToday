# 01 设置页与档案昵称管理

Status: ready-for-agent

## 交付内容

从首页进入独立设置页，集中管理本地用户档案与备份，支持昵称和手机号脱敏。

## 阻塞关系

Blocked by: 无，可立即开始

## 执行方式

使用 implement 执行实现与自动化验证，并提供人工设备检查步骤。

## 验收标准

- [ ] 首页档案入口 push 到设置列表，返回首页正常，页面沿用参考图的暖白背景、绿色主色、细边框与留白。
- [ ] 保留档案切换、新增、编辑、删除、导入、导出，新增推送设置入口供后续票据接入。
- [ ] 昵称选填，创建和编辑档案均可维护。首页优先昵称，无昵称展示脱敏手机号，设置同时显示昵称与脱敏手机号。
- [ ] 手机号可编辑且保留现有校验，稳定 UID 与排便数据归属不受影响。
- [ ] 昵称参与导入导出，档案删除确认和备份预览、事务一致性保持有效。
- [ ] 通过现有应用级 Widget 测试与真实业务对象、内存数据库验证导航、昵称持久化、档案隔离及备份恢复，记录静态分析和可用构建结果。

## 实施与验证（2026-11-10）

已实现独立设置页、昵称创建与编辑、手机号脱敏、档案切换及备份入口，推送设置可进入占位页，后续票据接入提醒能力。数据库升级至 v6，昵称随备份导出、校验与恢复，稳定 UID 保持数据归属。

静态分析无问题，完整测试 27 项通过。规范审查提出编辑入口命名可改进的建议，目前沿用“修改手机号”入口同时编辑昵称。规格审查发现的短 UID、同号档案昵称编辑及推送入口问题均已修正。

按用户要求由用户自行构建 APK 与设备自测。

人工检查步骤
1. 首页进入设置并返回，检查暖白背景、绿色主题和列表留白。
2. 新建带昵称档案，编辑昵称与手机号，检查首页昵称优先及设置手机号脱敏。
3. 切换档案检查记录隔离，导出后修改昵称再导入，确认预览与恢复。
4. 检查删除确认、最后档案删除后重新建档，以及推送设置占位页返回。
