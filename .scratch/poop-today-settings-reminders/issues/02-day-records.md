# 02 当日记录独立页面与四档填写

Status: ready-for-agent

## 交付内容

从日历日期或记录今天进入独立当日记录页，完成多条排便记录和未排便确认。

## 阻塞关系

Blocked by: 无，可立即开始

## 执行方式

使用 implement 执行实现与自动化验证，并提供人工设备检查步骤。

## 验收标准

- [ ] 日期和记录今天入口均 push 当日记录页，返回后首页数据同步，未来日期与具体时间限制继续适用。
- [ ] 新增时是否排便无预选且必选，以 ✅／❌ 单选展示。选择 ✅ 后依次展示排便量和通畅度，两项无预选且必填。
- [ ] 排便量仅 💩×1～4，移除新增表单的自定义量级，通畅度保持困难、一般、顺畅。
- [ ] 选择 ❌ 隐藏并清空量与通畅度，当天可多条 ✅，但与唯一的未排便确认互斥。已有排便改为 ❌ 先确认删除，已有 ❌ 新增排便自动解除确认。
- [ ] 保留具体时间选填、点击记录编辑、侧滑删除。编辑回显已有值，删除最后一条恢复尚未填写。
- [ ] 表单和列表按参考图视觉语言调整，以本轮字段顺序和量级为准。
- [ ] 应用级测试验证必选、字段顺序、量级范围、多记录、互斥转换、编辑删除及页面返回，业务入口和备份输入保持有效校验与事务一致性。

## 实施记录

已实现独立当日记录路由、是否排便必选、量在前通畅度在后的四档表单、互斥转换、编辑回显和侧滑删除。返回首页后重新读取数据。旧版有效量级仍允许备份往返，新增业务入口限制为 1～4。

自动化验证通过全量 26 项测试及静态分析。code-review 的规范轴与规格轴发现返回重复确认、编辑清空后绕过必填、旧量级备份往返和孤儿控制器，均已修复。APK 构建按用户要求取消。

### 人工设备检查

1. 从日历历史日期和“记录今天”分别进入，检查独立返回导航及首页刷新，确认未来日期不可选。
2. 检查三项无预选及必填提示，确认量级 1～4、量在通畅度前，切换 ❌ 后字段清空。
3. 同日保存两条，编辑时间及选项，检查未来时刻被拒绝，侧滑删除最后一条后显示尚未填写。
4. 已有记录切换 ❌，分别取消和确认删除，再新增 ✅，确认解除未排便状态。
5. 有未保存改动时点击返回和系统返回，确认仅提示一次。对照参考图检查真机字号、留白、细边框和绿色选中态。

设备运行及最终视觉验收待用户执行。
