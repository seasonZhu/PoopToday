# 04 单档案提醒端到端验证

Status: ready-for-agent

## 交付内容

从推送设置开启默认提醒，通过真实本地通知到达当天记录入口，验证后续完整提醒实现所需的平台能力。

## 阻塞关系

Blocked by: 01 设置页与档案昵称管理

## 执行方式

使用 implement 执行实现与自动化验证，并提供人工设备检查步骤。

## 验收标准

- [ ] 推送设置页沿用参考图视觉语言，当前档案预置当地时间 10:00 和 22:00，默认不自动申请通知权限。
- [ ] 用户开启时申请通知权限，授权成功后启用，拒绝时展示真实状态并可再次按平台允许方式处理。
- [ ] 以单一可替换平台通知适配边界接入，配置按档案持久化且不参与备份。
- [ ] 在可验证的时间触发真实通知，通知携带档案定位信息。提供当天记录导航接入契约，02 完成后由后续票据验证最终跳转。
- [ ] 验证 Android、iOS 应用关闭后的跨日调度、当地时间、填写后取消和点击回调能力，记录平台限制、验证环境与实际结果，不能把替身测试作为设备通过。
- [ ] 提供实现所需的平台配置、适配器调度与取消测试及人工检查步骤。无法完成的设备验证明确标记待 06 验收，不虚报通过。

## 实施记录（2026-11-10）

已接入默认时间推送设置、主动授权、单一平台适配边界、本机按档案配置、30 天通知预排与填写后取消及 UID 点击导航契约。时间编辑不属于本票据。真实设备行为待 06 验收，未标记设备通过。实现限制与人工步骤见 [通知验证记录](../notification-validation.md)。

验证结果：`flutter analyze` 无问题，最终 `flutter test` 31 项通过。Android debug 构建长时间停留 assembleDebug 后停止，未确认构建通过；iOS 未构建。两平台设备验收仍待 06。已完成规范与规格双轴审查并修复通知故障阻断核心功能、初始化与重调度并发问题。
