# 每日排便记录 App 首版规格

Status: ready-for-agent

## 问题陈述

用户需要方便地记录每次排便的通畅度和排便量，通过日历回顾与补录历史。家庭共用设备时，需要区分不同人的数据。应用需要离线可用，并能备份和迁移数据，为未来接入后台保留兼容基础。

## 解决方案

使用 Flutter 开发简洁清晰的应用，优先交付 Android。以本地用户档案隔离数据，提供日历首页、记录编辑页和管理页。每条记录表示一次排便，支持同日多条、补录、自定义选项及明确的未排便确认。提供完整 JSON 备份、导入预览与事务化合并恢复。

## 实现决策

### 已确认的技术与模块边界

- 使用 Flutter，优先实现 Android。全部业务离线可用。
- 展示层包含日历首页、记录编辑和管理功能，采用简洁清晰的中文界面。
- 应用业务入口统一承接档案、记录、日期状态、选项和备份操作，供页面调用及行为测试使用。存储和设备时间通过边界接入，以便替换为临时数据库及可控时间。
- 本地存储必须支持持久化、事务和可升级的数据结构。具体数据库、状态管理、文件交互依赖及版本在工程基础任务中核实环境后选定，实施任务应记录选择依据及兼容范围。
- Android 最低版本、应用标识、撤销入口持续时间属于实施前配置项，尚未选定。

### 数据与规则

- 档案使用不可变稳定标识，手机号可变且有效档案间唯一，离线格式校验无需短信验证。切换无需密码。
- 排便记录保存稳定标识、所属档案、日历日期、可选具体时间及对应时区信息、两个选项的关联和选择时名称。所有可迁移数据具备适用的版本、修改时间和删除状态信息。
- 通畅度预设为困难、一般、顺畅，排便量预设为少、中、多，两维度必选且无默认选中。
- 自定义选项归属于档案和维度，名称去首尾空白后为 1～20 个字符，与预设及停用选项均不得重名。预设固定，自定义按创建顺序展示，支持改名、停用、重新启用，暂不强制映射等级。
- 日期状态由有效记录及未排便确认表达，尚未填写不得隐式解释为未排便。新增或移入记录解除目标日期未排便确认，删除或移出最后一条记录后原日期回到尚未填写。所有相关变更整体提交。
- 已有记录时确认未排便需确认删除当天记录。单条删除提供短暂撤销，同时恢复记录并撤回对应删除标记，若当天已确认未排便需提示解除确认。
- 删除档案清除手机号和所属业务内容，保留识别所需最小删除信息。手机号可复用，新档案使用新标识。
- 日历日期不随时区移动。保存和导入校验未来日期，具体时刻按保存的时区信息换算并与当前时刻比较。设备当前当地日期决定可填写日期范围。
- 日历周一开始，未来日期置灰不可进行记录操作。列表有时间记录升序，无时间记录随后按创建顺序展示。编辑有未保存改动时返回需确认，保存后首页选中记录的新日期。

### 备份格式与合并契约

- 使用带格式版本号的明文 JSON，包含全部档案、记录、未排便确认、选项、删除标记及档案合并映射。导出前告知敏感内容和未加密状态，允许用户选择保存位置或分享目标。
- 备份应反映一致的数据状态。解析与校验覆盖标识、归属、引用、维度、日期时刻及互斥规则，损坏、内部冲突、未来排便数据及不支持的高版本文件整体拒绝。支持的旧格式具有显式升级规则，首版不虚构尚不存在的历史格式。
- 导入预览不改变业务数据，展示新增、跳过、冲突及日期明细和档案映射选择，确认后原子提交。预览后若本机状态变化，提交时须重新校验并更新预览，保证所见结果与提交一致。
- 稳定标识相同且内容相同则跳过，内容不同保留本机并计为冲突，不同标识不按内容自动去重。
- 相同手机号不同标识时选择合并目标或跳过。合并保留记录原标识，同维度同名选项复用本机，其余导入为目标档案的自定义选项，保留历史名称。保存来源到目标的映射，再次导入沿用并展示。
- 删除标记阻止普通导入复活对应对象，已删除档案不能仅凭复用手机号恢复。合并映射和删除信息共同参与判断，映射不得形成无法解析的归属。
- 日期状态互斥冲突保留本机当天状态，跳过冲突内容并列出日期，本机尚未填写时接收有效备份状态。
- 空白设备恢复以备份时状态为限。导入文件的删除信息与本机有效数据相遇时沿用本机优先原则，保留本机有效内容并报告冲突，避免旧备份静默删除当前数据。

### 平台与迁移

- 关闭 Android 应用数据系统云备份，实际版本及设备迁移行为实施时核实验证。用户可主动将导出文件保存到云盘。
- 后台兼容以数据可迁移为目标，预留稳定标识、版本、修改时间、删除标记和数据库升级机制。后台绑定及同步协议待后台要求明确后设计。

## 测试决策

用户已确认以下测试边界。当前项目只有文档，没有已有代码、测试或可复用测试案例。

- 主要业务测试通过应用对外操作入口执行，结合临时实际数据库及可控时间，断言可观察结果、重新读取后的数据与错误结果，覆盖档案、选项、日期状态、记录及备份操作。
- 重点覆盖同日多条、最后一条删除与移出、未排便互斥、历史名称、跨时区、未来时间边界、删除撤销及重复操作。
- 备份测试覆盖导出再导入、重复导入、相同标识冲突、不同标识相似内容、档案合并、同名选项复用、删除标记、映射再次导入及跨设备恢复。
- 注入提交失败验证回滚，模拟预览后数据变化验证重新校验。组合覆盖合并档案后删除记录再导入，确保不会重复或复活。
- 文件校验覆盖损坏数据、无效引用、内部互斥、过高版本、未来排便数据及适用的旧版本升级规则。
- Flutter 页面测试覆盖必填项、选项初始状态、日历选择及禁用、未保存提示、档案切换、排序、删除确认与撤销、导入预览。
- Android 集成验证覆盖文件保存与分享、取消操作、重启持久化、数据库升级、系统备份配置及目标版本的设备迁移限制。
- 完成静态分析、自动化测试和 Android 构建检查，分别记录结果。构建通过与真实设备行为验证分别报告。
