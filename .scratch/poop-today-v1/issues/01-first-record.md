# 01 · 创建档案并完成首次排便记录

Status: ready-for-agent
Blocked by: 无，可立即开始

## 交付行为

首次打开创建档案，使用预设选项保存今天的一次排便并查看，重启后仍保留。

## 验收标准

- [ ] 建立可构建的 Flutter Android 应用，中文界面简洁清晰，完成创建档案到当天记录展示的完整操作。
- [ ] 手机号采用中国大陆 11 位格式校验，档案和记录使用不可变稳定标识，手机号与记录归属分离。
- [ ] 通畅度提供困难、一般、顺畅，排便量提供少、中、多，两项必选且初始不预选，记录日期为今天。
- [ ] 数据持久化，断网和重启后仍可读取，具备版本、修改时间和后续删除标记所需的数据基础。
- [ ] 核实本机 Flutter 与 Android 环境，确定并记录数据库、状态管理、Android 最低版本及应用标识，存储支持事务和升级。
- [ ] 建立统一业务操作测试入口，使用临时实际数据库与可控时间，覆盖创建、保存、重新读取与必填校验，并添加相应页面测试。
- [ ] 关闭 Android 系统云备份，完成静态分析、相关测试及 Android 构建，分别记录结果。

## 规格依据

每日排便记录 App 首版规格，已确认的九票据拆分。通过应用对外操作入口验证业务行为，页面测试验证用户交互。
