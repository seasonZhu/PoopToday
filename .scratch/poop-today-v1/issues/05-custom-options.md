# 05 · 自定义选项与历史名称保留

Status: ready-for-agent
Blocked by: 02, 04

## 交付行为

在管理页面维护档案专属的通畅度和排便量选项，并在记录页面使用。

## 验收标准

- [ ] 自定义选项按档案和维度隔离，支持新增、改名、停用及重新启用。
- [ ] 名称去首尾空白后为 1～20 个字符，同档案同维度与预设及停用选项均不得重名。
- [ ] 预设选项固定，自定义选项按创建顺序显示，停用选项退出新选择范围，自定义暂不映射预设等级。
- [ ] 已有记录保留选择时名称，选项改名或停用后仍可展示，编辑其他字段不会更新名称，主动重新选择才使用当前名称。
- [ ] 业务及页面测试覆盖长度、空白、重名、跨档案、改名停用重启用及历史记录编辑，重启后结果保留。

## 规格依据

每日排便记录 App 首版规格，已确认的九票据拆分。通过应用对外操作入口验证业务行为，页面测试验证用户交互。
