# 08 · 档案合并与重复恢复

Status: ready-for-agent
Blocked by: 07

## 交付行为

导入时选择已有档案作为合并目标，后续备份恢复能够沿用合并关系。

## 验收标准

- [ ] 相同手机号不同档案标识时，预览允许选择合并目标或跳过，确认后原子提交档案映射和业务数据。
- [ ] 同维度同名选项复用本机，其余导入为目标档案自定义选项，保持记录原标识与历史名称并正确映射引用。
- [ ] 保存来源到目标档案的合并映射，后续导入自动沿用并展示，映射无循环及无法解析的归属。
- [ ] 合并信息随完整备份导出及恢复，合并后重复导入保持幂等，不错误增加冲突或重复记录。
- [ ] 档案或记录删除后再次导入遵守删除标记，手机号复用不能恢复旧档案，合并目标删除后仍能识别来源数据的删除约束。
- [ ] 测试覆盖合并确认与取消、同名选项、合并后删除再导入、映射跨设备恢复、预览失效及提交失败回滚。

## 规格依据

每日排便记录 App 首版规格，已确认的九票据拆分。通过应用对外操作入口验证业务行为，页面测试验证用户交互。
