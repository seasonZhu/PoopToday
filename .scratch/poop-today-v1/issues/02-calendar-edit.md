# 02 · 日历补录与记录编辑

Status: ready-for-agent
Blocked by: 01

## 交付行为

从日历选择历史日期新增、查看和编辑多次排便，保存后定位到记录日期。

## 验收标准

- [ ] 日历周一开始，支持切换月份和返回今天，未来日期置灰且不可进行记录操作。
- [ ] 支持过去或今天同日多条记录，日期必填，具体时间选填，两个维度仍必选。
- [ ] 保存时按设备当前当地日期和时刻禁止未来输入，跨时区后历史日期固定，具体时间保留当地时间及对应时区信息。
- [ ] 有时间记录按时间升序，无时间记录随后按创建顺序排列，日历显示每日次数，未填写留空。
- [ ] 编辑记录可修改日期及其他字段，保存后刷新并选中新日期，未保存改动返回需确认放弃。
- [ ] 选项关联和选择时名称同时保存，只修改其他字段时保留原选项名称。
- [ ] 通过业务入口和页面测试覆盖补录、同日多条、排序、日期修改、未来时刻边界、跨时区与未保存提示，重启验证数据。

## 规格依据

每日排便记录 App 首版规格，已确认的九票据拆分。通过应用对外操作入口验证业务行为，页面测试验证用户交互。
