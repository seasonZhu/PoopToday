# 07 · 导入预览与基本恢复

Status: ready-for-agent
Blocked by: 06

## 交付行为

选择备份并预览差异，确认后完整恢复或合并，失败保持原数据。

## 验收标准

- [ ] 校验格式、版本、标识、归属、引用、维度、日期时刻及内部互斥，损坏、未来排便数据、内部冲突或高版本文件整份拒绝并说明原因。
- [ ] 支持的旧格式通过显式升级规则读取，首版仅覆盖实际存在的格式。
- [ ] 预览展示新增、跳过、冲突数量与日期明细，取消不改变业务数据，确认后事务提交，失败回滚。
- [ ] 同标识同内容跳过，不同内容保留本机并报告冲突，不同标识相似记录均保留，重复导入无重复记录。
- [ ] 本机删除标记阻止旧数据复活，备份删除信息遇到本机有效数据时保留本机并报告冲突。
- [ ] 按档案和日期处理状态互斥，冲突保留本机并列出日期，本机尚未填写时接收有效状态。
- [ ] 相同手机号不同档案标识时，此阶段支持明确跳过该档案及其数据，合并入口由后续票据交付。
- [ ] 预览后本机数据变化时重新校验并更新预览，重新确认后才提交。
- [ ] 通过业务及页面测试覆盖空白恢复、重复导入、文件拒绝、删除和日期冲突、预览失效及注入失败回滚，验证 Android 文件选择与取消。

## 规格依据

每日排便记录 App 首版规格，已确认的九票据拆分。通过应用对外操作入口验证业务行为，页面测试验证用户交互。
