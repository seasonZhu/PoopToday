# 06 · 完整备份导出

Status: ready-for-agent
Blocked by: 03, 04, 05

## 交付行为

在管理页确认明文数据提示后，将一致的完整备份保存或分享。

## 验收标准

- [ ] 导出具有明确格式版本的 JSON，覆盖全部档案、记录、未排便确认、选项、删除标记及合并映射字段，初始映射可为空。
- [ ] 备份来自一致的数据状态，稳定标识、归属、历史名称、日期时区及适用版本信息完整保留。
- [ ] 删除档案的手机号与业务内容不出现在备份中，恢复所需最小删除信息继续保留。
- [ ] 导出前明确提示未加密及包含手机号和排便数据，支持 Android 保存位置选择和分享目标选择。
- [ ] 取消及文件写入失败有明确结果，用户业务数据不受影响。
- [ ] 测试验证备份内容与一致性，完成文件保存分享的 Android 集成验证，区分自动化结果与设备验证结果。

## 规格依据

每日排便记录 App 首版规格，已确认的九票据拆分。通过应用对外操作入口验证业务行为，页面测试验证用户交互。
