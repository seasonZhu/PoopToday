# 04 · 多档案管理与隔离

Status: ready-for-agent
Blocked by: 01

## 交付行为

管理多个本地用户档案，切换、修改手机号和删除后正确展示所属数据。

## 验收标准

- [ ] 可新增并直接切换档案，无需短信和密码，有效档案手机号唯一，创建及修改均检查重复。
- [ ] 修改手机号不改变档案稳定标识及历史归属，档案之间记录和选项归属独立。
- [ ] 启动恢复上次档案并选中今天，上次档案不存在时选择剩余档案，没有档案时要求创建。
- [ ] 删除档案前二次确认并显示手机号及影响范围，清除手机号和所属业务内容，保留识别所需最小删除标记。
- [ ] 删除最后一个档案后进入创建页，创建完成才能继续记录，相同手机号可重新使用但产生全新档案标识。
- [ ] 通过业务入口、页面和重启测试验证隔离、手机号校验、删除取消及确认、最后档案删除和手机号复用。

## 规格依据

每日排便记录 App 首版规格，已确认的九票据拆分。通过应用对外操作入口验证业务行为，页面测试验证用户交互。
