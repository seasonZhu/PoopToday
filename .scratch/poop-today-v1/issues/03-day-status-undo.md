# 03 · 未排便确认、删除与撤销

Status: ready-for-agent
Blocked by: 02

## 交付行为

在日历区分未填写、确认未排便及已记录排便，支持删除与撤销并保持日期状态一致。

## 验收标准

- [ ] 日历展示三种日期状态，未填写留空，确认未排便与有效排便记录互斥。
- [ ] 新增或移入记录自动解除目标日期未排便确认，删除或移出最后一条记录后原日期回到尚未填写，变更整体提交。
- [ ] 有记录时确认未排便，提示并确认删除当天记录，取消操作不改变数据。
- [ ] 删除单条记录保存最小删除标记并提供短暂撤销，确定并记录撤销持续时间，撤销同时恢复记录和撤回对应标记。
- [ ] 撤销时当天已确认未排便需提示将解除确认，用户确认后原子恢复。
- [ ] 业务及页面测试覆盖最后一条删除、移出移入、确认与取消、撤销和互斥，注入失败验证无部分变更。

## 规格依据

每日排便记录 App 首版规格，已确认的九票据拆分。通过应用对外操作入口验证业务行为，页面测试验证用户交互。
